MemoryVLN: From Ego-Aware Memory Representation to Cross-Context Memory Reuse in Vision-Language Navigation

Anonymous Submission
Code Videos BibTeX

Turn a growing stream of first-person observations into compact, spatially grounded memory that can be retrieved within an episode and reused across contexts.

Abstract

Large vision-language models (LVLMs) have shown strong potential for embodied vision-language navigation (VLN), yet their performance degrades on long-horizon trajectories due to context-length limits, redundant historical observations, and unstable spatial alignment across time. These issues make it difficult to both compress long navigation histories and reliably reuse past spatial experience. To address these limitations, we propose MemoryVLN, a unified memory-driven navigation system built around memory construction and management. During memory construction, Long Sequence Compression employs forgetting-curve-inspired temporal sampling to preserve dense recent evidence and sparse yet representative distant observations under a limited token budget. Ego-Aware Memory Representation further integrates 2D semantic tokens, 3D geometric tokens, and 6D agent poses, allowing each memory to encode both what was observed and where it was observed. During memory management, Hierarchical Memory Bank maintains in-episode and context-level memories through cross-context warm-start and confidence-controlled write-back. Memory Enhancement then retrieves the Top-K relevant memories according to the current navigation state and fuses them with the current visual tokens. Together, these mechanisms transform raw navigation history into compact, spatially grounded, selectively retrievable, and reusable navigation experience. Extensive experiments on R2R-CE and RxR-CE demonstrate consistent improvements over the state-of-the-art baselines by a substantial margin (i.e., 2% and 6.5% in success rate).

Method

Memory construction turns raw observations into structured memory; memory management decides when that memory is stored, retrieved, and updated.

(a) Long Sequence Compression

An Ebbinghaus-inspired retention prior combines inter-chunk budget allocation with intra-chunk key-frame selection. Retention grows sublinearly as B(N)=min{N, max[Bmin, ⌊a+b√N⌋]}, preserving dense recent evidence and sparse representative distant landmarks under a bounded visual-token budget.

(b) Ego-Aware Visuospatial Representation

ViT-based 2D appearance tokens, frozen-VGGT 3D geometric tokens, and 6D agent poses are fused through a geometry residual. Each memory therefore encodes both what was observed and where it was observed, disambiguating visually similar locations.

(c) Hierarchical Memory Bank

A persistent Context-Level Bank warm-starts new episodes with the most similar prior and writes back only confidence-gated experience. An In-Episode Bank keeps recent frames in a FIFO short-term pool and consolidates distant history in a cosine-weighted long-term pool.

(d) Memory Enhancement

A frame-level query retrieves the Top-K memories from the joint short- and long-term pools. A softmax-weighted summary is interpolated with the current frame and injected as a residual into the current visual tokens before action prediction.

Implementation

MemoryVLN uses Qwen2.5-VL as the action-prediction backbone and keeps the VGGT geometry branch frozen.
